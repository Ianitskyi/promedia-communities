# promedia-communities

Каталог і карта медійних спільнот України — база посилань на медіа: сайт,
короткий опис, ключова ідея спільноти та посилання, де на неї підписатися.
Кожен запис прив'язаний до області, тож на схематичній контурній карті можна
натиснути область і побачити медіа звідти.

🔗 Локально: відкрийте `index.html` подвійним кліком, або

```
python -m http.server 8080
```

і зайдіть на http://localhost:8080

## Що всередині

| Файл | Призначення |
|---|---|
| `index.html` | Головна сторінка: контурна карта областей + список карток, пошук і фільтри |
| `css/style.css` | Стилі у брендових кольорах ПроМедіа (navy `#0d0c5c` + accent `#ffac33`), ті самі шрифти й фавікон, що на promedia.report |
| `js/app.js` | Рендер SVG-карти областей, карток, пошук, фільтри за областю й позначками |
| `img/ukraine-oblasts.svg` | Контурна SVG-карта областей України (джерело — див. розділ «Карта») |
| `data/communities.json` | Дані каталогу — єдине джерело правди для сайту |
| `.github/ISSUE_TEMPLATE/add-community.yml` | Форма заявки на додавання спільноти (премодерація) |
| `.github/workflows/deploy-pages.yml` | Автодеплой на GitHub Pages при push у `main` |
| `CNAME` | `communities.promedia.report` |

## Формат запису (`data/communities.json`)

```js
{
  "id": "unique-slug",
  "name": "Назва медіа",
  "region": "Львівська область",   // текст, що показується на картці
  "regionSlug": "lviv",            // id області на SVG-карті — див. список у js/app.js (OBLAST_LABELS)
  "city": "Львів",
  "website": "https://example.com",
  "description": "Короткий опис медіа (1-2 речення).",
  "communityIdea": "Ключова ідея спільноти — чому варто підписатися.",
  "communityUrl": "https://t.me/example",
  "platform": "telegram", // telegram | facebook | instagram | youtube | viber | website | other
  "badges": {
    "recommended": false, // на мапі рекомендованих медіа
    "whitelist": false,   // у білому списку ЗМІ
    "jti": false          // сертифікація Journalism Trust Initiative
  },
  "tags": ["investigative", "warJournalism"], // опційно, будь-яка підмножина — див. TAG_LABELS у js/app.js
  "status": "approved",   // approved-записи потрапляють на сайт; заявки на розгляді тримайте окремо або з іншим статусом
  "example": false        // true лише для ілюстративних seed-записів
}
```

`regionSlug` — один із 26 id, що відповідають областям на карті (`cherkasy`,
`chernihiv`, `chernivtsi`, `crimea`, `dnipropetrovsk`, `donetsk`,
`ivano-frankivsk`, `kharkiv`, `kherson`, `khmelnytskyi`, `kirovohrad`,
`kyiv`, `kyiv-city`, `luhansk`, `lviv`, `mykolaiv`, `odessa`, `poltava`,
`rivne`, `sumy`, `ternopil`, `vinnytsia`, `volyn`, `zakarpattia`,
`zaporizhia`, `zhytomyr`). Зверніть увагу: медіа зі штаб-квартирою в Києві
мають `regionSlug: "kyiv-city"` (місто), а не `"kyiv"` (область навколо
міста) — це дві різні фігури на карті.

⚠️ **Позначки `recommended` / `whitelist` / `jti` потрібно проставляти
свідомо**, звіряючись з актуальним реєстром білого списку ЗМІ та реєстром
сертифікації JTI — це не автоматично визначені поля.

Позначки й теги показуються лише на картці медіа (як опційні характеристики)
— на головній сторінці немає окремих кнопок-фільтрів за ними, лише пошук і
фільтр за областю.

## Наповнення даних: поточний стан

Репозиторій стартує з **6 ілюстративних записів** (`"example": true`) —
відомі національні й регіональні медіа з коректними сайтами, але без
перевірених посилань на конкретні спільноти (Telegram/Facebook) і без
підтверджених позначок. Це демонстрація структури каталогу, **не готовий
до публікації список**. Перед публічним запуском команді ПроМедіа варто:

1. Замінити `communityUrl` прикладових записів на реальні перевірені
   посилання на спільноти цих медіа (або прибрати запис, якщо такого немає).
2. Проставити позначки `recommended`/`whitelist`/`jti` за фактичним статусом.
3. Прибрати `"example": true` після перевірки або видалити запис.
4. Додати регіональні медіа з усіх областей — поточний набір покриває лише
   кілька міст.

## Премодерація нових спільнот

Сайт **не має бекенду** — це, як і `journalism2026`, повністю статичний
GitHub Pages сайт. Додавання нової спільноти працює через **GitHub
Issues**:

1. Кнопка «Додати спільноту» на сайті відкриває заповнювану форму
   [`add-community.yml`](.github/ISSUE_TEMPLATE/add-community.yml) —
   заявник вказує назву, сайт, посилання на спільноту, опис, ключову ідею,
   місто та область (випадаючий список, що збігається з областями на карті).
2. Issue автоматично отримує лейбл `needs-review`.
3. Модератор перевіряє заявку: коректність посилань, реальність спільноти,
   правильність області, доречність позначок.
4. Якщо все гаразд — модератор додає новий об'єкт у
   `data/communities.json` (вручну або через PR) зі `"status": "approved"`
   і закриває issue.
5. Якщо заявка не підходить — модератор закриває issue з коментарем-поясненням.

Це той самий підхід «без бекенду», що вже використовується в
`journalism2026` (оновлення даних теж відбувається комітами в гілку).

## Деплой і DNS

GitHub Actions (`deploy-pages.yml`) автоматично публікує сайт на GitHub
Pages при кожному push у `main`. Щоб субдомен `communities.promedia.report`
запрацював, потрібно:

1. У налаштуваннях репозиторію → **Settings → Pages** переконатися, що
   Custom domain = `communities.promedia.report` (файл `CNAME` це вже задає,
   GitHub Pages підхопить автоматично після першого деплою).
2. У DNS-панелі домену `promedia.report` додати `CNAME`-запис:
   ```
   communities.promedia.report  →  ianitskyi.github.io
   ```
   (аналогічно до вже налаштованого запису для `ratings.promedia.report`).
3. Увімкнути **Enforce HTTPS** у Settings → Pages після того, як DNS
   пропагується і GitHub видасть сертифікат.

## Карта

Замість реалістичної супутникової/вуличної карти сайт використовує
**схематичну контурну SVG-карту областей** — так простіше сприймати
географію на рівні областей, без зайвих деталей вулиць чи рельєфу.

Контури взято з пакета [`@svg-maps/ukraine`](https://www.npmjs.com/package/@svg-maps/ukraine)
(`img/ukraine-oblasts.svg`), який адаптує мапу [MapSVG](https://mapsvg.com/maps/ukraine)
за ліцензією [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) —
атрибуція вказана у футері сайту. `js/app.js` після завантаження SVG додає
обробники кліків на кожну область (`<path id="...">`), лічильник медіа
(`<text>` по центру фігури) та підсвітку — без сторонніх бібліотек для
карт.
